# AlphaForge v2 Core Patch

Questa patch trasforma l'app da semplice ranking ETF a piattaforma AlphaForge Intelligence.

## Nuove funzioni

- Motore `core/` separato per dati, metriche, scoring ETF, scoring azioni, confronto e watchlist.
- Analisi libera di ETF e azioni da ticker.
- Confronto tra strumenti.
- Watchlist azioni iniziale in `data/watchlist.csv`.
- Output watchlist in `AlphaForge_Watchlist.csv` e `AlphaForge_Watchlist.xlsx`.
- Dashboard pubblica `index.html` ridisegnata.
- App Streamlit multipagina con sezioni:
  - ETF Ranking
  - Analizza Strumento
  - Confronta
  - Watchlist
  - AI Assistant controllato
- Beta tester aggiornato.
- Workflow automatico aggiornato per committare anche la watchlist.

## Uso dopo installazione

1. Esegui `AlphaForge Patch Installer` con questa patch.
2. Esegui il beta test rapido.
3. Esegui il beta test completo.
4. Esegui `Auto update ETF Intelligence App`.
5. Controlla GitHub Pages.
